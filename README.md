# 철도적성 훈련실

철도 종사자 정기적성검사(철도안전법 시행규칙 제41조, 별표 13)의 반응형 검사를 대비하는 브라우저용 인지기능 훈련 프로그램입니다. 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 훈련 항목

| 영역 | 항목 | 대상 |
|---|---|---|
| 주의력 | 복합기능 (운전): 속도 유지 + 시계 고르기 + 청각 "7" | 운전 |
| | 복합기능 (관제): 컨베이어벨트 숫자넣기·박스추가 + 청각 "7" | 관제·신호 |
| | 선택주의: 단어 뜻과 글자색 일치 판단 | 공통 |
| | 지속주의: 짧은 자극에만 반응 | 운전 |
| 인식 및 기억력 | 시각변별 (운전): 신호등 세트 비교 | 운전 |
| | 시각변별 (관제): 노선도 세트 비교 | 관제·신호 |
| | 공간지각: 장애물을 피한 최단경로의 건물 고르기 | 공통 |
| | 작업기억: 색칠된 칸 위치 기억 | 관제·신호 |
| 판단 및 행동력 | 추론: 수열·문자 규칙 | 특별검사 |
| | 민첩성: 기호-숫자 표 보고 순서대로 누르기 | 공통 |

각 항목은 연습(짧게)과 실전(공식 문항 수·시간) 모드를 지원합니다.

## 키보드 배치

홈 위치(F·J 돌기)에 손가락을 올린 상태에서 조작합니다. 키는 물리적 위치(`KeyboardEvent.code`)로 인식하므로 한/영 상태와 무관합니다.

| 손가락 | 키 |
|---|---|
| 왼손 약지·중지·검지 | S · D · F |
| 오른손 검지·중지·약지·새끼 | J · K · L · ; |
| 양손 엄지 | Space |

- 2지선다: F / J
- 4지선다: D · F · J · K
- 복합기능(운전): F 가속, D 감속(누르고 있기), J K L ; 시계 1~4, Space "7"
- 복합기능(관제): J 홀수 상자, K 짝수 상자, F 박스추가, Space "7"
- 민첩성: S D F J K L = 버튼 1~6

## 유의사항

- 등급(A~E)은 훈련용 추정치입니다. 실제 검사는 지정 적성검사기관의 전용 장비로 시행하며 화면과 채점 기준이 다를 수 있습니다.
- 관제 복합기능의 "숫자넣기·박스추가" 규칙은 공개 설명이 부족해 홀짝 상자 규칙으로 구성했습니다.
- 기록은 브라우저 `localStorage`에만 저장됩니다.
